# Verbal & visual identity

Identity is positioning made tangible: what the brand says and how it looks and sounds.
Every choice here should trace back to the positioning. When you present a choice, state
the *why* — a client can defend "precise, high-contrast type because we sell rigour" but
can't defend "we liked it."

Two halves: verbal, then visual.

---

## Verbal identity

### Name (only if in scope)
Most engagements keep the name — changing it destroys equity and is expensive. Change it
only for a real reason (legal, merger, a name that actively misleads or limits). If in
scope:
- Generate names against the positioning; explore descriptive, evocative, invented, and
  abstract routes.
- Screen every shortlist candidate for: pronounceability, spelling, meaning in relevant
  languages, domain and social handle availability, and **trademark risk** (recommend a
  professional clearance search before commitment — never assure a name is legally clear).
- Present 3–5 with rationale; note the shortlist you rejected and why.

### Tagline
The tagline expresses the brand idea in a memorable line. Draft ~10, shortlist 3, recommend
1 with reasoning. Test each: is it true, ownable (not a competitor's line), and does it say
something (avoid empty "excellence, delivered" filler)? Distinguish an external tagline
(for the audience) from an internal rallying line (for the team) if both are useful.

### Messaging house
The repeatable story, structured so anyone can tell it consistently:
- **Rooftop / one-liner**: the single sentence (from positioning).
- **Pillars (3–4)**: the supporting themes, each with a headline + 1–2 sentences + proof.
- **Boilerplate**: the standard 50–100 word "about" paragraph.
- **Elevator pitches**: 10-second and 30-second versions.
- **Proof bank**: reusable stats, credentials, client names, guarantees.

### Tone of voice
- 3–4 voice principles, each as "we are X, not Y" (e.g. "plain, not dumbed-down";
  "confident, not boastful"). The contrast is what makes it usable.
- Do/don't examples: rewrite one real sentence the brand-way and the wrong-way.
- Grammar and mechanics: any house rules (sentence case vs title case, em-dash policy,
  Oxford comma, banned words, reading level). Mirror the client's existing rules if they
  have them.

## Visual identity direction

This skill defines **direction**, not final artwork: the principles and specifications a
designer executes, or that seed a design tool. Say this plainly to the client.

### Design principles (3–4)
Translate personality into visual rules. E.g. "high contrast" (editorial serif + generous
space) for a rigorous, premium brand; "warm and human" (rounded forms, real photography)
for an approachable one. Each principle should exclude something — that's how it guides.

### Logo direction
- Wordmark, lettermark, symbol+wordmark, or emblem — and why it fits.
- Requirements: legible at 16px favicon size, works in one colour and reversed, scalable,
  distinctive against the competitive map. Note clear-space and minimum-size rules.
- For a refresh: what to keep (equity) vs modernise.

### Colour
- Primary, secondary, and neutral roles with a rationale tied to positioning and category
  differentiation (don't default to category colours if you want to stand out).
- Provide hex values and usage rules (where each is allowed, proportions — often a
  dominant neutral with an accent used sparingly).
- Check WCAG contrast for text/background pairs; state which combinations are for text.

### Typography
- A heading face and a body face (or one versatile family), each with a real fallback
  stack. Justify the pairing against the principles (e.g. editorial serif heads for
  authority, neutral grotesque body for clarity).
- Scale, weight and case rules; keep it disciplined (2 families, few weights).

### Imagery & iconography
- Photography style (subject, lighting, treatment, real vs stock), illustration or icon
  style, and any data-viz style. Give rules, not just adjectives.
- If real photography isn't ready, specify an interim (consistent abstract/art-directed
  placeholders) rather than mismatched stock.

### Motion (if relevant)
- How the brand moves: pace, easing, where motion is used and where it isn't. Restraint
  reads as premium; constant animation reads as noise.

### Handoff
List what a designer needs to produce final assets (logo suite, colour tokens, type
licences, templates, a brand guidelines document). Offer to build a living brand-guidelines
page or a set of templates as a follow-on.

## Output format
```
# Identity — [Client]

## Executive summary
## Verbal
### Name (if in scope) / Tagline / Messaging house / Tone of voice
## Visual direction
### Principles / Logo / Colour (with hex + contrast) / Type / Imagery / Motion
## Designer handoff checklist
```
